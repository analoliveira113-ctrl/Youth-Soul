
# Youth Soul

Plataforma web desenvolvida como projeto acadêmico, com o objetivo de conectar crianças, jovens, famílias e instituições a informações, oportunidades e iniciativas de desenvolvimento social.

## Sobre o projeto

A Youth Soul será uma plataforma web responsiva, composta por um site institucional e uma loja virtual integrada, chamada Alma Livre.

## Funcionalidades previstas

- Apresentação institucional da Youth Soul.
- Divulgação de iniciativas e projetos.
- Informações sobre oportunidades e apoio aos jovens.
- Área de parceiros.
- Loja virtual Alma Livre.
- Catálogo e detalhes dos produtos.
- Carrinho de compras e finalização de pedidos diretamente pelo site.

## Tecnologias

- JavaScript
- React
